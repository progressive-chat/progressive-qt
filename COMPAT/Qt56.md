# Qt 5.6 port notes (Spectral 464 → Progressive Chat Qt)

Base: Spectral tag 464 (Oct 2018). Upstream required Qt 5.10+ (`BUILD.md`).
Goal: build and run on **Qt 5.6**, desktop and **Android 4.0 (API 14) down
to 2.3 (API 9)**.

## Done in this commit

- QML imports downgraded to Qt 5.6 levels: QtQuick 2.6, Controls 2.0,
  Material 2.0, Layouts 1.2, Models 2.2, Window 2.0.
- `Qt.labs.platform` (tray, StandardPaths) removed from the startup path:
  tray icon moved to `imports/Progressive/Compat/TrayIcon.qml`, loaded via
  `Loader` only on non-Android desktop; `DownloadableContent.qml` uses the
  `cacheLocation` context property from C++ `QStandardPaths`.
- `Qt.labs.settings` removed: `imports/Progressive/Setting/Setting.qml` is a
  LocalStorage-backed singleton with the same keys
  (`showTray`, `confirmOnExit`, `darkTheme`, `pressAndHold`).
- C++ keeps the Qt &lt; 5.10 `invokeMethod(..., "getThumbnail", ...)` fallback
  (`src/imageprovider.cpp`); `.pro` documents the C++11 fallback for old NDKs.
- Android packaging skeleton: `android/AndroidManifest.xml`
  (minSdk 9, targetSdk 14), `ANDROID_PACKAGE_SOURCE_DIR` wired in the `.pro`.
- QML modules renamed `Spectral.*` → `Progressive.*`, singleton
  `MSettings` → `PSettings`.

## Known remaining work

1. **Qt Quick Controls 2 on stock Qt 5.6**: Controls 2 shipped in Qt 5.7.
   Stock Qt 5.6 has only Controls 1.x. Options: (a) bundle a Controls 2
   backport with the Android package, (b) build against Qt 5.6.3 +
   qtquickcontrols2 tech-preview, (c) rewrite QML to Controls 1.4.
   Current imports target Controls 2.0 as the lowest common denominator.
2. **Android 2.3 (API 9)**: Qt 5.6 officially supports API 14+. API 9–13
   needs a custom Qt build (Necessitas-style) and NDK r10e / GCC 4.8–4.9
   with `CONFIG += c++11`. The manifest already declares minSdk 9.
3. **Notifications on Android**: D-Bus/win32/mac managers excluded for
   `android` in the `.pro`; in-app banners are the fallback.
4. **Material style 2.0 vs 2.2**: minor theming deltas possible; visual QA
   on Qt 5.6.3 pending.
5. **C++ class names** `SpectralRoom`/`SpectralUser` kept for now to keep the
   diff reviewable; rename to `ProgressiveRoom`/`ProgressiveUser` later.

## Verify

- `qmake progressive-qt.pro && make` with Qt 5.6.3 desktop.
- `qmllint`/`qmlscene` smoke test of `qml/main.qml` (tray Loader must stay
  inert when `Qt.labs.platform` is absent).
- `androiddeployqt` bundle install on an Android 4.0 emulator; then 2.3.
